Identité visuelle de la plateforme
============================================

Objectif
--------

Définir une identité visuelle simple, cohérente et professionnelle pour le frontend HMS.

L'objectif est de reprendre l'esprit visuel du projet de gestion de projets déjà réalisé, tout en l'adaptant au contexte hôtelier.

Style général
-------------

Le style retenu est :

```
dashboard moderne
clair
professionnel
sobre
orienté gestion hôtelière
inspiré du projet de gestion de projets existant
```

Référence visuelle
------------------

Les captures du projet existant montrent une interface avec :

-   fond général clair
-   sidebar verticale à gauche
-   menu actif en brun/marron
-   contenu principal centré avec beaucoup d'espace
-   tableaux sobres
-   cartes statistiques simples
-   badges de statut colorés
-   boutons primaires foncés
-   formulaires et modals minimalistes
-   typographie discrète et professionnelle

Ce style sera repris pour HMS afin de garder une cohérence visuelle avec les travaux déjà réalisés.

Palette de couleurs
-------------------

| Usage | Couleur recommandée | Description |
| --- | --- | --- |
| Couleur principale | Brun / marron foncé | Boutons principaux, menu actif, actions importantes |
| Couleur secondaire | Brun clair / beige | Hover, fonds légers, accents secondaires |
| Fond principal | Gris très clair | Arrière-plan de l'application |
| Cartes | Blanc | Cards, formulaires, tableaux |
| Texte principal | Gris très foncé | Titres et textes importants |
| Texte secondaire | Gris moyen | Descriptions, labels, informations secondaires |
| Bordures | Gris clair | Séparation légère entre les blocs |

Couleurs des statuts Room
-------------------------

| Statut API | Libellé UI | Couleur |
| --- | --- | --- |
| AVAILABLE | Disponible | Vert |
| RESERVED | Réservée | Bleu |
| OCCUPIED | Occupée | Rouge ou orange foncé |
| CLEANING | Nettoyage | Violet |
| MAINTENANCE | Maintenance | Orange |
| OUT_OF_SERVICE | Hors service | Gris |

Typographie
-----------

La typographie doit rester simple, lisible et professionnelle.

Recommandation :

```
font sans-serif
titres visibles mais sobres
labels courts
textes secondaires discrets
pas de surcharge visuelle
```

Ton visuel
----------

L'interface doit donner l'impression d'un outil professionnel utilisé par :

-   un manager
-   un réceptionniste
-   un administrateur
-   un responsable housekeeping plus tard

Règles UX
---------

-   Les actions principales doivent être visibles.
-   Les filtres doivent être faciles à comprendre.
-   Les statuts doivent être lisibles rapidement.
-   Les erreurs doivent être affichées clairement.
-   L'utilisateur doit toujours comprendre ce qui se passe.
-   Le design doit rester sobre et cohérent avec l'ancien projet.
